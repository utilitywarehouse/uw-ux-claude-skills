# Mastering PARA — The Architect's Guide to Digital Organisation

## The PARA method

PARA organises information by **actionability** rather than subject. Picture a clean vertical stack of four tiers, descending from most urgent to historical storage.

| Category | Definition | Time horizon | Examples |
|---|---|---|---|
| **Projects** | Short-term efforts with a specific goal and deadline. | Days to months | *Launch new website; plan a research study; ship a redesign.* |
| **Areas** | Ongoing standards or responsibilities requiring maintenance. | Indefinite | *Health; finances; a product you own; a team you run.* |
| **Resources** | Topics or interests kept for future reference (the "library"). | Long-term | *Design inspiration; a framework you keep coming back to.* |
| **Archives** | Inactive items from the previous three categories. | Historical | *Completed projects; work that's wrapped up.* |

### Goal vs. standard

The distinction between a Project and an Area is the most common point of confusion.

- **Projects require execution** toward a finish line — a specific, closable outcome.
- **Areas require maintenance** of a standard, with no finish line. For example, "Redesign the onboarding flow" is a Project; "Onboarding" as a product area you own is an Area.

## Filing something new

The "subject-based" filing trap — sorting by topic instead of by what it's for — is a graveyard for notes, because subjects are too broad to be useful on a busy day. Instead, work down this checklist and file where you'll actually see it again:

1. **Projects** — which active project does this move forward right now?
2. **Areas** — if no project, which ongoing responsibility does it support?
3. **Resources** — if no area, which topic or interest does it belong to?
4. **Archives** — if none of the above, it's probably done, not new.

### The kitchen metaphor

Think of the four folders like a professional kitchen. Accessibility should dictate where something goes:

- **The stove (Projects):** what you're actively cooking — needs to be immediately at hand.
- **The fridge (Areas):** what you check daily or weekly — needs regular attention.
- **The pantry (Resources):** ingredients for future use — neatly tucked away, but findable.
- **The freezer (Archives):** cold storage for things you might need again, much later.
