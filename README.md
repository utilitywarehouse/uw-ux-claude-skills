# UW UX Claude Skills

Shared [Claude Code](https://claude.com/claude-code) skills for the UW UX team, packaged as a plugin.

Owned by Richard Lang.

📖 **[Read the docs](https://utilitywarehouse.github.io/uw-ux-claude-skills/)** — install steps, and what each skill does.

## What's in here

`plugins/ux/skills/` — skills like `new-project-setup`, `end-session`, `knowledgebase-health-check`, `figma-dev-handoff`, `research-transcript-cleaner`, and more.

## Contributing

This repo ships only through pull request. See the `propose-skill` skill (`plugins/ux/skills/propose-skill/SKILL.md`) for the full workflow — it opens the PR for you, it doesn't merge it.
