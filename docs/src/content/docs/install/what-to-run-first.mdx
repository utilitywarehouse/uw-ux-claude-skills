---
title: Set up your knowledge base
description: The first skill to run once the plugin is installed.
---

If you've never used this before, the first skill to run is:

```
/ux:setup-my-knowledge-base
```

It builds your personal knowledge base from scratch — folders, a starter `CLAUDE.md`, your own `About Me` note — links you into the team's shared Research Repository and product wikis, and then hands off into `/ux:new-project-setup` so you leave with one real project started, not an empty shell. See [Your knowledge base](/knowledge-base/) for what that structure looks like once it exists, and [setup-my-knowledge-base](/skills/setup-my-knowledge-base/) for the full walkthrough.

If your knowledge base already exists, skip straight to [new-project-setup](/skills/new-project-setup/) instead — `setup-my-knowledge-base` deliberately refuses to run a second time.
