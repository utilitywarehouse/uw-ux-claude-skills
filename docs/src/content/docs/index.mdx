## What this actually is

This repo ships a Claude Code **plugin** called `ux`, containing around a dozen **skills** — packaged instructions that teach [Claude Code](https://claude.com/claude-code) how to do specific pieces of UX work the way this team does them: setting up a personal knowledge base, scaffolding a new research project, cleaning and coding interview transcripts, writing up a finished study, auditing a knowledge base for rot, and more.

Skills are namespaced under the plugin they ship from. That means the command you actually type is **`/ux:setup-my-knowledge-base`**, not `/setup-my-knowledge-base` — the `ux:` prefix is not optional, and it's the first thing that trips people up. See [Install](/install/) for the full picture.

## Where this lives

The plugin's source is [`utilitywarehouse/uw-ux-claude-skills`](https://github.com/utilitywarehouse/uw-ux-claude-skills) on GitHub — public, so anyone can read the skills even without team access. This documentation site is built from the `docs/` folder in that same repo, so a change to a skill and a change to its docs can ship in the same pull request.
