Imagine this scenario. You start a new chat (session), but you have more than one active project in your knowledge base, and your message doesn't specify the project you're referring to. Claude has no way to guess it right, and a wrong guess just wastes a round trip fixing it.

This skill stops that problem. It looks at what is actually inside `1-Projects/` right now. It shows you a short list. You pick one. Claude loads that project.

You can either type `/ux:new-session` at the start of every new chat, or Claude will offer to run it automatically, if your first message doesn't already make the project clear.

## What it does, step by step

<Steps>

1. **You start a new chat.** Either type `/ux:new-session`, or just begin typing your prompt.

2. **Claude checks your message.** If you've already made it clear which project you're referring to, Claude just gets on with it — the skill isn't needed.

3. **Otherwise, Claude offers to run this skill for you.** This is where it kicks in.

4. **It checks your `1-Projects/` folder to see what's active.**

5. **No projects yet? Claude asks if you want to set one up.** Only if you say yes does it hand off to the `new-project-setup` skill to build one.

6. **Otherwise, you get a short list of your active projects to pick from.** So you can tell Claude which project to work in. Projects are grouped by area, most recently worked-on first. Two extra options are always there too: "Not working in a project" and "Check Archives".

7. **Once you pick, Claude loads that project's rules and history** (its `CLAUDE.md` and `MEMORY.md` — see [CLAUDE.md and memory](/knowledge-base/claude-md-and-memory/)). It's instantly up to speed.

</Steps>

<Aside type="tip">
  This list stays a plain numbered list on purpose. Fancier pickers cap out at a handful of options — a plain list keeps working no matter how many areas and sub-projects your vault grows to.
</Aside>

<Aside type="tip">
  Naming the project in your first message (e.g. "let's work on Sign-up") means this skill isn't needed — Claude loads that project's rules and history straight away.
</Aside>
