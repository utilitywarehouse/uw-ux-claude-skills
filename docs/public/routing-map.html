The routing map

One knowledge base, six routes. Every prompt starts in the same place — CLAUDE.md reads it and picks the route it takes to the right folder. Seven real prompts — step through them below.

0-Inbox/Daily notes created in Obsidian — reference for context on a day, not a task list or an outstanding-items queue.
1-Projects/Any current or past project — the biggest, busiest route.
WikiFirst port of call for any question about the project — read before the project folder, not alongside it.
2-Areas/Tasks.mdA single file, not a folder — add, delete, or update a line under its Work or Personal heading.
2-Areas/Company Knowledge/Org structure & terminology, not product-specific — one layer above any project's own Wiki, checked second.
TransferA project prompt can go on to Company Knowledge when its own Wiki doesn't cover something — not its own trip, just a link between two folders.
3-Resources/Useful links.mdPointer to a specific saved link.
4-Archives/Work that's ended — a finished project or closed area. Read for history; never edited or treated as current status.
